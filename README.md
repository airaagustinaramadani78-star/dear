## 🚀 Cara Menjalankan

### Menggunakan Google Apps Script

1. Buka Google Apps Script.
2. Buat project baru.
3. Salin file `Code.gs`.
4. Buat file HTML bernama `index`.
5. Masukkan kode website ke dalam file `index.html`.
6. Buat file HTML bernama `JavaScript`.
7. Masukkan kode JavaScript ke dalam file `JavaScript.html`.
8. Deploy project sebagai Web App.
9. Buka link website yang telah dibuat.

### Menggunakan GitHub Pages

Jika menggunakan versi HTML, CSS, dan JavaScript biasa:

1. Upload file website ke repository GitHub.
2. Buka Settings → Pages.
3. Pilih branch `main` dan folder `/ (root)`.
4. Klik Save.
5. Tunggu hingga website berhasil dipublikasikan.
